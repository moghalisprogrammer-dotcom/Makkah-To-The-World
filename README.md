# فعالية يوم السياحة العالمي 2026 — كلية مكة الأهلية

نظام تسجيل وحضور لفعالية واحدة، بواجهة عربية وإنجليزية، قاعدة MariaDB/MySQL، تذاكر QR، بريد تأكيد، ولوحتي إدارة واستقبال لأربع بوابات.

## الوظائف

- تسجيل حتى السعة المضبوطة (800 افتراضيًا)، والتحقق من الحقول وتسجيل الموافقة.
- اختيار ورشة واحدة من الورش الثلاث المتزامنة، أو حضور الفعالية دون ورشة.
- إصدار رقم تسجيل ورمز QR سري، وإرسال التذكرة والبرنامج والموقع وملف التقويم بالبريد عبر Resend.
- دخول مدير وأربعة موظفين بصلاحيات مخزنة في SQL وكلمات مرور مملحة ومجزأة.
- مسح QR أو البحث اليدوي، وتسجيل الدخول مرة واحدة مع سجل تدقيق.
- فلاتر حسب الورشة والعمر والحالة، إحصاءات، تصدير CSV آمن، وإعادة إرسال التذكرة.

## التشغيل المحلي

يتطلب Node.js 20.19+ وDocker Compose. ينشئ الأمر التالي أسرار تطوير محلية عشوائية في ملفات مستثناة من Git:

```bash
npm ci
node scripts/prepare-local.mjs
docker compose --env-file .env.local up -d
npm run db:setup
npm run dev
```

تفتح الواجهة على `http://localhost:3000`، لوحة المدير على `/admin`، استقبال البوابات على `/check-in`، وصندوق البريد التجريبي Mailpit على `http://localhost:8026`. حسابات التطوير وكلمات مرورها تُكتب محليًا في `local-access.txt`؛ لا ترفع هذا الملف أو `.env.local`.

## النشر

دليل إعداد خادم Ubuntu مستقل، قاعدة البيانات، Resend، PM2 وNginx موجود في [DEPLOYMENT.md](./DEPLOYMENT.md). يستخدم هذا التطبيق المنفذ `3001` محليًا، وقاعدة MariaDB على `127.0.0.1:3307`، ويترك `kaizenksa.com` على إعداداته الحالية.

## إعداد Resend

أنشئ مفتاح API على Resend، وأضف إلى DNS سجلات التحقق التي يعرضها Resend للنطاق المرسل. استخدم عنوانًا من النطاق الموثق مثل `events@kaizenksa.com` في `EMAIL_FROM`، واحفظ `RESEND_API_KEY` في ملف البيئة على الخادم فقط. يرسل النظام QR مرفقًا inline، تفاصيل الفعالية، رابط الخرائط، البرنامج، الورش وملف تقويم ICS. لا يحتوي البريد على مفاتيح أو أسرار.

## البيانات والخصوصية

يحفظ النظام الاسم والبريد والجوال والجهة والمسمى والفئة العمرية والورشة والحضور. يتطلب التسجيل موافقة صريحة للاستخدام التنظيمي، ولا تُرسل البيانات لخدمات QR خارجية. صلاحيات API محمية بالجلسة وقيود الأصل ومعدلات الطلب. خزّن ملف البيئة والنسخ الاحتياطية بأذونات محدودة، وحدد سياسة الاحتفاظ والحذف مع الجهة المنظمة.
