# فعالية يوم السياحة العالمي 2026 — الواجهات

واجهة عربية وإنجليزية متجاوبة للتعريف بالفعالية، والمسارات، والبرنامج، والورش، والموقع، والتسجيل، ولوحات عرض الإدارة والاستقبال.

## حالة هذه النسخة

هذا المستودع يحتوي الواجهات الأمامية فقط. يمكن إكمال نموذج RSVP لمعاينة تذكرة ورمز QR تجريبيين داخل جلسة المتصفح؛ الرمز غير صالح للدخول، ولا يُحفظ التسجيل مركزيًا أو يُرسل بريد. صفحات الدخول والإدارة والاستقبال لا تتضمن تسجيل دخول أو تحققًا أمنيًا. ربط التسجيل الفعلي والتذاكر والبريد ومسح QR يحتاج إلى خادم وقاعدة بيانات، وهما غير موجودين في هذه النسخة. لا تستخدمها لاستقبال بيانات زوار حقيقيين.

## تشغيل الواجهة

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
```

لإنشاء نسخة ثابتة للنشر:

```bash
npm run build
```

تُنشأ ملفات النشر الثابتة في `out/`. إرسال التسجيل إلى `/api/register` وبقية عمليات الإدارة تبقى معطلة حتى ربط الخدمات الخلفية.

## الصفحات

- `/` الدعوة التفاعلية ومعلومات الفعالية والتسجيل.
- `/registration/success` واجهة تأكيد التذكرة.
- `/login` معاينة دخول فريق التنظيم.
- `/admin` معاينة لوحة الإدارة وفلاتر الحضور والورش.
- `/check-in` معاينة واجهة الاستقبال.

## الهوية والملفات

الشعارات والصور والخطوط والموسيقى الاختيارية موجودة داخل `public/`. مصادر الصور وتراخيصها موثقة في [ASSET-CREDITS.md](./ASSET-CREDITS.md).
